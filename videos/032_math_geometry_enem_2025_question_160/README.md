# ENEM 2025: Tangent Function

This directory contains the mathematical notes, computational visualization, figures, animation, and exported documents prepared for the YouTube lesson on the tangent-function problem from ENEM 2025.

## Video

[Watch the lesson on YouTube](https://www.youtube.com/watch?v=fvKghpRJkY8)

## Main materials

- [`funcao_tangente_questao_Enem.ipynb`](funcao_tangente_questao_Enem.ipynb): principal computational notebook and worked solution.
- [`questao_160_enem2025_funcao_tangente.pdf`](questao_160_enem2025_funcao_tangente.pdf): formatted problem material.
- [`tangent_a0_b1_c1_d0.mp4`](tangent_a0_b1_c1_d0.mp4): animation used to illustrate the tangent function.
- [`fig01.png`](fig01.png): supporting figure.
- [`tex/`](tex/): LaTeX export and auxiliary figures generated from the notebook.

## Purpose

The files are retained together because the directory serves as the public companion archive for the video. The notebook is the principal editable computational document; the PDF, figures, and video are publication and presentation outputs.
