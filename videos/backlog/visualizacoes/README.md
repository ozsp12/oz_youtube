# Galeria de visualizações

Material complementar com exemplos estáticos e animados em Matplotlib, Seaborn e Plotly.

- [`exemplos_visualizacoes.ipynb`](exemplos_visualizacoes.ipynb): painel de gráficos estáticos;
- [`exemplos_graficos_animados.ipynb`](exemplos_graficos_animados.ipynb): exemplos de linhas, histogramas, bolhas, mapas de calor, distribuições, superfícies e outros gráficos animados.

Os notebooks funcionam como catálogo de técnicas, não como recomendação automática. A escolha gráfica deve seguir a pergunta analítica, a estrutura dos dados e a tarefa perceptual exigida do leitor. Animação é útil para demonstrar evolução, mas dificulta comparações quando o leitor precisa memorizar estados anteriores.
